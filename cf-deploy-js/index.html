🧩 Xuất theo lưới (nhiều ảnh để ghép)

Chia khung nhìn hiện tại thành nhiều ô nhỏ, mỗi ô xuất 1 file ảnh PNG riêng, giữ đúng tỉ lệ đã chọn. Ghép các ảnh lại theo tên file (r=hàng, c=cột) để ra bản đồ đầy đủ.
⚠️ Trình duyệt sẽ hỏi xin phép "tải nhiều file" ngay khi file thứ 2 chuẩn bị tải — hãy bấm Cho phép / Allow thì các ô còn lại mới tự tải tiếp, nếu không quá trình sẽ dừng giữa chừng.
